What's next

Where this is going

Texas was the proof of concept. Here's what comes next through the PEAK Award program.

More states

The pipeline is designed so I can swap a config file and data source to run the same analysis on a new state. Next targets include North Carolina, Ohio, Georgia, Louisiana, and Alabama. All of these have active redistricting litigation or Voting Rights Act concerns that make them worth examining.

Multiple election proxies

Right now I'm using the 2024 presidential race as the partisan proxy. A stronger analysis would test against Senate, Governor, and Attorney General races too, making sure the finding isn't just an artifact of one specific election.

Machine learning layer

The current method is MCMC simulation, not ML. But there's a natural extension: using ensemble metrics (seats, efficiency gap, mean-median, compactness scores) as features to train a classifier that predicts gerrymandering likelihood. That would let us quickly flag suspicious maps without running a full chain every time. I'm also exploring whether graph neural networks could learn structural patterns in district graphs that correlate with manipulation.

Stricter constraints

Adding compactness requirements, county preservation rules, and Voting Rights Act compliance checks to the ensemble. This makes the generated maps more realistic and the analysis more legally defensible.

Public tool

Eventually I'd like to make this accessible to people who don't write code. Upload an enacted plan, run the analysis, get back a report card. Something like the Princeton Gerrymandering Project's grading system, but powered by fresh ensemble runs rather than pre-computed grades.
