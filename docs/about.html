About this project

Hi, I'm Bina. I'm an undergraduate at Northeastern University studying at the D'Amore-McKim School of Business.

This project started during a Dialogue of Civilizations trip to Belgium and France ("Data and Software in International Government and Politics"), where I got into conversations with my professor about whether computational methods could be used to test political claims about how district lines get drawn.

I started learning about Markov chains and Monte Carlo methods through 3Blue1Brown and StatQuest videos, which led me to the MGGG Redistricting Lab's academic work and their GerryChain library. The more I read, the more I realized the right approach here wasn't traditional machine learning but statistical simulation. This project is the result of that exploration.

Beyond this research, I'm interested in how the same kind of statistical fairness testing applies in other areas: algorithmic fairness in lending, model validation in finance, and responsible AI more broadly. The core question is the same across all of them. Did a process produce a fair outcome, and how would we know if it didn't?

This project is not affiliated with any political party, campaign, or advocacy organization. The analysis is nonpartisan. The code is open source.
